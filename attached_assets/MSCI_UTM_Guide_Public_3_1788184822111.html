utm_term — Keywords vs. Ads (auto-populated by Google)
For standard campaigns (pp/rt): utm_term is auto-populated by Google with the matched keyword. Do not set it manually. This is how you distinguish keyword-level traffic in reporting.
For Performance Max (pmax): No creative control, no utm_term. Google manages asset groups automatically.

How to identify keyword vs. ad creative in reporting:

SignalWhat it tells youWhere to find it
utm_termThe keyword that triggered the ad (auto-tagged by Google)Google Ads > Keywords report; GA4 session_keyword
utm_content [3] = ads_subtypeWhether ad was prospecting (pp) or retargeting (rt)Parse position [3] of utm_content string
utm_content [6] = audience_segmentWhich audience segment the ad group targetedParse position [6] of utm_content string
utm_content [8] = detailsLanding page / ad creative descriptorParse position [8] of utm_content string
Google auto-tag (gclid)Full ad creative data (headline, description, ad ID)Google Ads > Ads & Assets report

The Marketing Source field is authored on the back end of forms — both Pardot/Msci.com form handlers and 1-click Salesforce LeadGen API forms. It follows the structure Mktg | [type] | [channel] | [source] and is the primary signal that determines which SLA outreach process is triggered in Salesforce. This value is visible under Pardot Marketing Source in Salesforce.

HAND-RAISER — 5-day outreach SLA
Explicit opt-in — the person has actively taken an action that signals intent (form fill, event registration, ad form submit, in-app or MCP interaction). Field is set at time of form submission or API call.
SCORED — 10-day outreach SLA
Implicit signal — no single action triggered the lead. A combination of behaviours (page views, content downloads, event registrations, newsletter subscriptions) accumulates enough score to qualify. Currently limited availability — turned off in some configurations.
